# Parametric Equations Viewer

An interactive WebGL-based 3D viewer for parametric equations.

## 🎨 [View the Interactive Viewer](https://adrian-locke.github.io/Parametric-Equations/viewer.html)

### Controls
- **Drag** to orbit around the model
- **Right-drag** (or Shift+drag) to pan
- **Scroll** to zoom in/out
- **Double-click** to reset view

### Features
- Interactive 3D visualization
- Wireframe overlay toggle
- Ground grid and axes display
- Auto-rotate option
- Adjustable lighting and rotation speed
- Dark mode support
- Save PNG snapshots
- Responsive design
